# Android 设计约束

开始先读 [AGENTS](../AGENTS.md)、[当前交接](../docs/HANDOFF.md) 与 [紧凑布局规范](../docs/COMPACT_UI_GUIDELINES.md)。本文只保留设计方向，不重复逐版本实施/验收记录；历史细节在固定Git提交可恢复。

只读Hub、桌面显示语义为参照，按触控和屏幕适配；不猜缺数据，不自行恢复小组件，不通过像素相似宣称全部能力对等。保留浅深/中英文/系统大字/减少动效；导航八入口完整可见，自然文字换行，不能靠缩字或语义节点掩盖裁切。触控范围独立于视觉密度，普通控件48dp，设置菜单特例仅按紧凑规范。

现有数字/菜单/披露动效要可中断、快速反向、后台收束，不增加统一装饰性全页动画；虚拟帧不当真机触感/FPS。主页/完整列表/历史各自保持来源与状态身份，金额只按COST_MODEL，不重复记账。Hub/SSE/缓存安全边界沿用合同，不借UI调整重构全局架构。

验收只更新VALIDATION，未完成项只更新HANDOFF；不新建版本报告或扩写README。截图和日志遵循AGENTS的外部位置与保留期限，私密资料不得公开。
