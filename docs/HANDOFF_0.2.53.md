## 修改与原因

- 导航菜单去掉额外 2dp 行间距，统一 12sp 标签和 44dp 选中行视觉；每个菜单项及底部独立动作仍保留至少 48dp 触控范围。底部切换动作取消覆盖整个触控矩形的默认波纹，保留点击、长按和可访问语义。
- 设置/折叠内容打开时直接绘制 live 子树，不再回放此前裁切的退出图层。旧版在长 Lazy item 滚动后，语义节点可见但新露出行像素纯黑，新增像素测试已复现。关闭仍即时卸载子输入/Popup，并在有限退出动画结束、离开可见区域或后台时释放缓存。仍保留退出捕获开销，不据此声称 CPU、FPS 或内存改善。
- 额度展开详情统一使用共享 quotaTextStyle 和当前字体/字号，保留账户遮罩及隐藏项过滤。重置/更新时间按手机本地时区显示为 `yyyy-MM-dd HH:mm:ss`，不展示原始毫秒或 Z；缺失和无效日期显示已有不可用文案。
- Release 使用独立正式 RSA 签名；私钥及配置在仓库外，源码仅读取配置并在缺失时拒绝打包，不回退 Debug 签名。签名维护见 [RELEASE_SIGNING.md](RELEASE_SIGNING.md)。

## 安装与迁移限制

**这是首次正式证书版本，不能直接覆盖此前 Debug 证书的 0.2.52-dev 等 APK。** 已在隔离模拟器验证 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，旧安装与状态未更改。不要为安装新包而直接卸载或清空手机旧版；涉及旧版连接、设置与加密缓存的数据迁移须另行安排。正式签名 APK 可用于首次安装，后续正式版本必须沿用同一证书且递增 versionCode。此限制也写入 GitHub Release 首段。

没有上传私钥、密码、私有配置、截图附件中的用户数据或生产数据，没有部署/修改 NAS、Hub、Lucky。当前任务到 GitHub 发布及下载核验完成后停止；下一项是用户手机上的视觉、滚动和安全迁移验收，不自动执行。
