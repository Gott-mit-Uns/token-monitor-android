# 额度设置状态与 Hub 账号摘要

桌面基线为 v0.68.0 固定提交 `5d2db368d8313415763860d594de00e46a663418`，依据 `src/electron/renderer/limits/providerPresentation.js`、`app.js` 的提供商设置行与原始 CSS。安卓仍是独立 Kotlin/Compose 的 Hub 查看器。

提供商名称旁保留 6dp 状态圆点；其他状态使用原始 9sp、1/5dp 内边距、5dp 圆角标签。过期状态优先于成功状态，来源只在成功或过期记录上显示。Codex RPC 的 App/CLI/Managed 与其他提供商来源沿用已有固定源码映射。没有上报记录时不推断启用、禁用或登录状态。

提供商展开按钮采用原始 4dp 圆角，避免 Material 默认胶囊裁切名字和标签。成功状态按原始 `themePresets.js` 随实际背景切换：深色为 `#b7ead4`，浅色为 `#18794e`；状态与来源颜色独立于用户自定义强调色、图表色。绿色圆点由展开按钮的无障碍状态描述说明，不覆盖供应商名称。套餐优先使用 `planLabel`，兼容旧 `accountLabel`，不把纯账户名称当作套餐。

同一提供商设置行通常采用最后一条记录；MiMo 按原始规则优先最后一个成功产品，否则选择 Console 而非 Membership。它的两个产品仍是两个额度记录，账号数量按已有 MiMo 逻辑身份规则合并。

右侧数量及展开列表只描述 Hub 实际上报的账号，标题明确为“Hub 上报的账号”。桌面端账户管理摘要还依赖本机账户配置、凭据配置标志和登录表单 DTO，这些并未出现在 Hub 额度记录中。安卓不伪造这些配置，也不提供登录、新增账户、采集能力开关或凭据编辑。只读列表显示已有身份、套餐、状态和来源，遵守本机邮箱遮罩，原始记录不变。

`tools/capture-limit-settings.cjs` 直接执行固定桌面模块，生成 2,556 个状态/来源用例、5 个记录选择用例及原始中英文文案。`tools/capture-limit-settings-layout.cjs` 执行原始提供商复制区域代码并加载原始 CSS，生成两个语言的公开对照图。安卓专项检查同时覆盖混合成功/失败账号、过期记录、无上报提供商、邮箱遮罩、中英文和零附加网络读取。

公开模拟数据与真实联调数据分开验证；真实名称、账号和应用画面不进入归档。主页 Token 动效、前台 SSE、HTTPS/私网 HTTP 和本机显示偏好保持原有范围。Lucky 公网入口与实体手机的验证、其余桌面差异及用户体验验收仍未完成。
