## 原始依据与实现

| 原始代码 | 本轮对应行为 |
|---|---|
| `sessionRows.js/sessionRowsForPeriod` | 正用量会话；最近活动、用量、费用和名称顺序；标题/工具模型/活动层级；归档状态；ID显示规则 |
| `sessionRows.js/sessionTokenRate` | 有时长的输出用量平均生成速度；输出取`min(outputTokens,timedOutputTokens)`，无时长或输出时不显示读数 |
| `sessionRows.js/sessionCacheHitPercent` | 缓存读取占`inputTokens + cacheReadTokens + cacheWriteTokens`的比例；没有缓存观测时省略读数；不足1%保留`<1%` |
| `sessionRows.js/sessionModelTooltipEntries` | 多模型提示包含各模型用量/占比和未分类剩余；完整列表提示显示完整数值 |
| `sessionLive.js`、`app.js/updateRowContext` | 最近会话的已用/剩余上下文、警戒色和源缓存时效；上下文提示独立使用西式简写；归档会话不冒充运行 |
| `app.js/updateRowLive` | 完整会话列表仅在运行时显示绿色小点，完成/闲置不绘制首页的旋转/完成图形 |
| `sessionRows.js/groupBackgroundReviewRows` | 普通会话保留原顺序，审查记录汇总到列表末尾；归组内按最新时间排序，保留原始费用汇总 |
| `app.js/backgroundReviewRunNode` | 审查分组内显示模型/时间、ID、用量、费用和用量条；可查看Hub汇总，不请求本地正文 |
| `breakdownRenderPolicy.js` | 每页100条、首尾禁用、数据减少后自动收敛到有效页；用量条基于完整可见集合的最大值并保留2%非零下限 |
| `styles.css`的会话模式 | 标题/数值12、辅助信息10、上下文9；66最小数值列、7/8间距、5高用量条和底部分隔线；Android保留48触控范围 |

`messageCount`对应计费用量记录，沿桌面显示固定英文`call/calls`，不是聊天消息条数。多模型标签沿桌面显示`N models`。源字段没有记录时不补造调用、缓存命中或速度。

标题仅接受Hub已允许分享的160码点内文本；本机隐藏时完整列表回到工具/模型标题，SSE撤回标题后已打开的汇总和加密原始缓存同步替换。只保留汇总元数据，过滤普通会话通道中的Reasonix本地/合成条目和旧的合成ID形状；不读取`nativeSessions`、转录正文、本机日志、文件路径或新增会话详情接口。

列表、分页、归组和提示均为已读数据的显示投影，操作不增加Hub请求。时效刷新仅在前台发生，退出或后台沿用原SSE关闭边界。完整会话投影只在会话页执行，避免其他页面额外排序整套会话。
