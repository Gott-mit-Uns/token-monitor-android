# 0.2.5首页月份与日期交互

状态：开发包0.2.5-dev（versionCode14）已实现并验证本轮范围，整体桌面一致性和用户体验验收仍进行中。此前费用/币种与分类检查保留在COST_DISPLAY_PARITY.md。

## 固定来源与行为

基线v0.68.0/5d2db368d8313415763860d594de00e46a663418。usageCharts.js的heatmapSvg将月份文字放在网格下方，heatmapCalendar/rollingYearHeatmap将每月1日所在列作为月份起点；app.js的compactMonthLabel按当前语言显示短月份，setupHomeActivityHover按日期身份保持实时更新中的提示。

Android继续用星期日起始的9dp格/3dp间隔、近12个日历月和向最新端定位；月份轴以每月1日所在列为起点，中文/英文短月份随应用语言变化，末月文字预留宽度避免月初截断。14个原桌面参考增加直接monthLabels列/月份键对照，含闰年、跨年和月初边界。

桌面悬停在手机上适配为点击日格，打开紧凑日期详情；保留日期身份，在实时值变化时更新数字。另提供48dp“查看当天详情”、上一天/下一天按钮，未来日不可选择，滑动不触发选日；间隔与月份文字没有日格目标。趋势页仍有已有48dp逐日列表。紧凑详情采用8dp圆角/细边框/等宽数字，与密集图表一致；没有复制桌面鼠标悬停光晕动画。

详情显示完整Token、当前币种已知费用和未定价，保留未知、明确零值和无记录的区别。首页today的展示副本同时覆盖当前未定价数，不保留冻结的历史提示；统计、加密历史和额度原币种不改。切换主周期不把今日日历变成累计用量，独立历史日历仍沿用来源截止日。
