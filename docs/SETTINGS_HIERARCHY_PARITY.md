八个桌面分组中，窗口和采集没有进入查看器。桌面托盘、窗口置顶/穿透/玻璃、快捷键和 Agent/本地文件采集是桌面进程功能；手机查看 Hub 不需要这些权限或后台工作。Android 主题模式、设备速率选择、安全区和最小 48dp 独立触控范围作明确适配。视图与首页模块顺序通过上移/下移调整；没有把静态拖拽图形当作已实现的手势。

原始顶层分组初始关闭，同时只展开一个。原始图标形状、11sp 标题、9.5sp 摘要、面板与分隔线语义色、34×20 开关及 14dp 开关圆点进入实现。小型控件保留原始视觉比例，触控范围独立扩大。分组离开再回来保留本机展开状态和非敏感编辑状态，连接凭据输入不进入保存状态。

主页总量动效继续采用桌面 1000ms / 周期 800ms 和 easeOutQuart。外观中的减少动态效果按原始三态处理：system 跟随 Android 动画比例，on 直接显示最终值，off 保留过渡。运行中改为 on 会收束当前数字；不会增加网络读取或后台显示帧。已有总量实录见 HEADLINE_MOTION_PARITY.md。

模型排行的 tokens/cost 开关使用原始比较逻辑：存在已知、非未归属的正费用时按费用排列，随后用 Token 和名称决定并列顺序；没有可靠正费用时回到 Token。条形使用选定指标，完整 Token 数值仍显示；首页模型摘要沿用原始 Token 排名。`tools/capture-settings-semantics.cjs` 直接执行固定桌面模块，生成 12 个动效决策、17 个排行比较实例。

偏好保存格式升为 V13，在 V12 末尾追加动效三态及模型排行。读取旧格式时补系统动效和 Token 排行默认值，不主动改写旧资料；实际修改时保存新格式。原始 Hub 加密缓存、数据与金额不重算。

尚未声称所有设置控件与原始像素一致。工具管理、额度配置和输入编辑控件仍有 Android 实现差异；首页活动配置的位置与原始子分组、更多视图的配置入口继续核对。真实 Lucky、实体手机、正式签名和用户体验验收也不由模拟器检查替代。整体目标保持进行中。
