# 普通操作文字与桌面颜色用途

本页记录0.2.42的调用清单和内容颜色范围。0.2.43进一步按用途对齐完整按钮与禁用透明度，见 [本轮范围](THEME_HISTORY_ACTIONS_PARITY.md)；旧清单、测试与截图仍属于旧包。

固定参考桌面 v0.68.0，提交 `5d2db368d8313415763860d594de00e46a663418`。原始 `src/electron/renderer/styles.css:539–546` 为普通操作指定 `color: var(--text)`，并未让所有按钮文字继承强调色。安卓旧 TextButton 默认使用 Material primary，导致订阅读取、取消/应用、明细关闭、背景图片等操作在自定义强调色下偏离正文色。

本次以 DesktopTextButton 统一 19 个文件中的 46 个调用：普通内容默认使用本机主题 onSurface，禁用内容为其 0.5 alpha。已有两组显式 ButtonColors 保留，以维持选中周期和历史数据着色；内容自己的 muted/error 色也保留。普通颜色、选中颜色和数据颜色不能通过一次全局 primary 替换混为一种用途。

这里只对齐普通操作的内容颜色。禁用透明度不是所有桌面按钮的统一规则，例如原始 settings-actions 的禁用 opacity 为 0.38；当前通用原生禁用色 0.5 不代表这类全部状态已经逐像素一致。首次连接的实心提交按钮、启动器小组件的边框操作和手机弹窗布局仍是具体平台适配，继续按用途核对。

实际界面检查使用公开 Hub 样例和红色强调色：选中的 DAY 保持红色，订阅读取和入口使用正文色；打开真实文字颜色弹窗后，页面预览红色，Apply/Cancel 使用保存的弹窗基线；无效输入禁用 Apply，Cancel 可用且不保存；强调色改为绿色并 Apply 后，DAY 改为绿色，主题编码与提交次数匹配，额外 Hub 读取为零。检查读取实际 TextLayoutResult 内容颜色，不只比较主题变量或包装函数。

六种显示配置覆盖浅色、深色、窄屏大字号、横屏、平板及减少动画，主要页面另作浅深色渲染。最终报告与安装包绑定见 `evidence/button-colors/final`；完整普通检查的结果以该目录最终封存文件为准。桌面整页沿用上一轮不可变公开捕获并逐字节核对，源指纹与调用清单见 `evidence/button-colors`。旧版本渲染不会标成新 APK 通过。

本轮同时修正数字逐帧状态的读取范围，详见 [运行测量](DESKTOP_NUMBER_RUNTIME.md)。用户额外动效要求已撤销；这次没有固定导出 33 帧，也没有把普通按钮颜色或测试计数作为整个桌面复刻目标完成的证明。
