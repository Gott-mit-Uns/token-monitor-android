# 0.2.1 工具列表对齐

2026-10-09。当前结果是桌面对齐的继续修正，整体用户验收仍未通过。

依据桌面v0.68.0固定提交5d2db368d8313415763860d594de00e46a663418的工具设置与列表行为，独立实现显示、隐藏、置顶、移动及重置。仅导入桌面公开的35项可管理工具ID、名称和图形；Gemini及Hub未来扩展的未知工具保持可见，不误设为不可配置的隐藏状态。

## 已实现行为

- 未手动排序时，列表按用量降序；置顶工具按置顶顺序显示，其余保持用量顺序。
- 在置顶区移动工具保留用量模式；移动未置顶工具进入完整手动顺序并清除置顶。重新置顶清除手动顺序。这些模式转换依据桌面实现。
- 工具视图与主页工具摘要使用同一显示设置。隐藏只影响列表，总Token、总费用、设备统计与其他视图仍是完整Hub数据。
- 仅有费用、没有Token计数的工具不会被丢弃；未知计数保持未知。全部隐藏显示说明，保留总量与恢复入口。
- 设置支持工具搜索；搜索期间禁用移动，避免看不到完整上下文时改动位置。显示和置顶仍可操作。提供重置顺序/置顶与全部显示两个独立操作。
- 图标沿用桌面形状。触摸按钮保留48dp目标，窄屏/大字允许名称与数字分行，横屏通过实际滚动操作验证。

公开显示偏好升级为二进制V4，使用工具ID的UTF编码，不使用可随目录变化而改变的序号。V1/V2/V3仍可读取，新字段默认为空；读取旧文件不会擅自重写。原主题、语言、标签隐私和主页模块顺序保留。列表校验失败不覆盖原文件，写入继续使用原子替换。
