# 0.2.7主题、字体与文字大小

状态：0.2.7-dev（versionCode16）实现本轮本机外观范围，普通回归与真实Hub检查通过。整体桌面体验和用户验收继续进行，测试计数不代表用户认可。

## 固定来源与本机显示

基线v0.68.0/5d2db368d8313415763860d594de00e46a663418，renderer/themePresets.js、shared/fontSettings.js、renderer/app.js与styles.css。独立原生实现，外观不请求或写入Hub设置。

提供桌面的石墨、碳黑、纸白三套预设，以及强调色、图表色、背景色、文字色、次要文字色五项六位RGB输入。三套预设使用固定来源值；界面色、图表色、语义成功色各自独立。首页趋势/活动、趋势折线、逐日活动和设备用量使用当前图表色，工具/模型堆叠仍沿用对应品牌/系列色。默认蓝色活动色阶保持来源的四级原值，自定义图表色按来源规则生成色阶。此前页面写死蓝灰渐变导致换主题后背景混色，现改为选定主题的整页背景，并检查实际屏幕边缘像素。

TM1四字段与TM2五字段代码的编码、解码、大小写/空白规范及错误版本遵循固定桌面函数。导入TM1恢复默认图表蓝色，非法代码或非法RGB不覆盖已有选项。可选择/复制当前主题代码；代码只包含界面颜色，不包含连接、字体或Hub数据。浅色/深色/跟随系统入口保留，选择其一清除自定义界面颜色并保留字体、文字大小、币种和其他设置。

界面字体和总量数字字体独立。界面默认等宽，总量默认系统展示字体，与桌面默认角色一致；支持应用默认、系统、等宽、自定义，数字另可跟随界面。字体名称沿用来源的160字符和字符规范，Android使用设备已有字体；无法取得的字体回退到系统字体，不下载字体文件。CSS字体名称列表在Android选择首个名称，不能保证桌面安装字体或整个CSS回退链在手机存在。

文字大小采用来源的标准1、较大1.1、最大1.2倍，放大标签与数据文字，不改变总Token及图标尺寸；Android系统文字缩放继续生效。长数字、大字体与底部切换的分行判断包含应用文字大小。手机保留48dp触摸，原桌面鼠标控件尺寸不直接照搬。

V8在已有偏好记录后追加外观；V1–V7读取不重写，主题/语言/隐私、工具、主周期、活动与币种汇率保留。非法新记录保存前拒绝，原文件不变；加密连接与源快照/历史的格式不变。Android使用不透明界面，macOS/Windows的窗口玻璃、穿透及窗口深度不复制为手机数据功能。
