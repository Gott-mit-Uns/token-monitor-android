## 实现方案

- 关于：原顺序为Android检查更新、当前版本说明、Android发行页、许可；现顺序为Android检查更新、桌面端最新版、当前安装版本说明、许可。当前说明仍用安装versionName精确标签。桌面单独匿名客户端查询Javis603/token-monitor稳定Release，显示版本/打开说明；失败、限流、无网络如实显示并重试，不影响Android检查更新。
- 字体：共用两行标签列与选择控件宽度，宽度测量文本；重置按钮保留原恢复默认字体行为并明确区分界面/总量无障碍名称。小屏/大字体自然分行，不裁值、不缩触控目标。
- 单价/模型别名：复用页内折叠组件与页面字号，保留加载、筛选、分页、完整单价/来源/版本。详情页内展开；返回关闭折叠并隐藏键盘。只读区域没有未保存写入。展开、搜索与分页保存状态。
- 额度/说明：14dp复选框视觉保留整行48dp触控；标题与说明2dp内间距，相关组后8dp留白，正文自然换行；巡检常规设置说明、币种、外观、字号、主画面/会话、主页额度及减少动态。
- 订阅：移除再次进入同一列表的“订阅”按钮，当前区域直接展示原列表/合计/详情；保留明确“刷新订阅”与初次加载。Android既有只读账户/订阅能力不变。
- 多设备：手机与Hub复用采集卡组件形成两列，同行自然等高、文本换行；准确型号2304FPN60C映射 Xiaomi 13 Ultra，不改变设备ID或身份。手机始终只读查看。现已核实Hub合同没有友好主机名字段，因此显示连接回执中的DNS主机名，数字IP如实显示名称未知并保留地址；离线展示上次目标，不从同名采集设备或IP推测DXP4800。
- 记录明细：每日月日历/每月12宫格，标今天、选中与未来、支持跨月跨年。复用HistoryRanges和Hub monthly行，日历不重算月总量、不发起逐格请求；旧图表/活动保留在可展开分析。完整数值与归属在所选详情，零、无记录、未加载、失败及未来分开。日期键沿用既有Hub历史口径，今天标记沿用现有应用时区时钟；未对无时区历史擅自转换日期。

## 首次失败与定位

首轮 Lint 在测试源仍编辑时发生 Kotlin FIR/UAST findFirCompiledSymbol 内部崩溃；稳定源码重跑完整 Lint 通过，没有排除测试文件或增加 suppression。初次测试编译的 DpRect 尺寸导入和中点访问已修正，产品尺寸没有因此改变。

首轮 36 项 UI 有 6 项失败，原始 APK 和日志封存于 ui-first：恢复夹具重复挂载 MainActivity 内容；旧动效夹具没有明确选择 count，而默认模式已是 roll；旧选择菜单仍断言 48dp，与原有 compactSettings 的 36dp 策略不符。分别修正夹具挂载、显式动画模式和限定 compact 菜单断言，保留行为、进度和边界检查。

三项文字布局严格溢出断言（说明、设置标题、Hub 名称）经诊断确认：文字节点按字形宽度收缩，而段落保留父列最大宽度。例如 Hub 名称为 309px 节点、368px 段落，行右边 308.914px，没有纵向溢出。改为固定列内 fillMaxWidth，与采集卡策略相同；保留严格 hasVisualOverflow 断言，没有缩小字体或点击目标、放宽容差。

另修复页码恢复：LaunchedEffect(query) 会在恢复时归零，改为只在用户实际改变搜索时回第一页。恢复测试保留非空查询、第二页和所选单价详情，再验证新的 Hub 数据会更新显示。

发布前独立源码审查发现并修复跨时区 P1：手机本地日历落后于 Hub 时，原未来日期判断会隐藏已经接受的权威行。现在先遵循既有范围，再保留真实行（含零、未知或重复键），只有无行的未来日期禁选；导航上限同时覆盖真实 Hub 日／月。没有更改 HistoryRanges 的总量、日期键或月度统计。新增单元及 UI 用同一时刻的洛杉矶／上海日期覆盖跨日、跨月、跨年及返回后重新前进。

小屏系统字体 2.0 矩阵首轮另发现测试宿主使用真实动画起点而 Compose 使用虚拟帧时钟，导致等待空闲超时；统一夹具时钟，不关闭产品动画。旧字体独立性断言同时更换了总量字体，窄屏不同字宽的合法适配会影响最终字形大小；改为先在相同总量字体下严格验证界面字号独立性，再保留 Mono／Serif 字体渲染及完整无溢出断言。保留原始失败回执，未以缩字、放宽溢出断言或清除数据绕过问题。

跨时区修复后的联合候选（仍为 0.71.0-01/code74，非最终分发版本）完整构建通过：481 单元测试、0 失败／错误／跳过；完整 Lint 0 错误、102 警告、1 提示。应用 SHA-256 `36a9bd24d7bdce2f1fb466892425f90819f9617344e6550cfcad4bfc050c6cae`，测试 APK `1232bb6b2834af70bbb133e3c8d647f93985696a6764635f4efbc7075be7dd8e`。此处只记录候选构建身份，最终版本、UI 复验与发布回执另记，不混同为正式包测试。
