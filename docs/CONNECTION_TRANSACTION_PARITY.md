# 手动连接替换的事务行为

已封存开发版0.2.24-dev/code33，桌面参考仍固定v0.68.0提交`5d2db368d8313415763860d594de00e46a663418`。本轮修正安卓换Hub的失败与并发行为，不改变Hub只读范围。技术检查通过不代表用户验收或整体目标完成。

新地址先通过公开健康角色检查，再读取并解析认证统计，最后原子保存加密缓存。只有这些步骤全部成功，才一起替换地址、凭据和显示来源。认证、协议、数据解析或保存失败均保留原来的连接与缓存；原连接仍可继续SSE，失败原因保留在编辑表单中。取消后回到原连接摘要。对同一地址和凭据的真实401仍停止自动重试。

切换到不同Hub或更换账户时清空旧来源的历史、别名、订阅、模型与价格详情，再读取新来源。仅调整同一Hub的备用入口时保留对应缓存。连接修订标记确保新旧Hub历史版本号相同时也会重新读取明细。提交序号确保界面不会把提交前的健康旧快照误判成新连接成功，并丢掉失败草稿。

后台或默认网络变化会取消尚在网络验证的新连接，迟到响应无法替换缓存。已验证且开始本机原子写入时立即停止网络，待提交或回滚确定后，再按当前前台状态及HTTPS策略恢复读取。首个失败地址只保留为草稿，返回前台不自动重试未保存地址。

不增加依赖、权限或持久化格式。显示偏好仍为V15，加密Hub记录仍使用已有格式。主页Token变化动效保留1000ms更新、800ms周期切换、连续更新从当前数字继续、精确整数终点及系统/开启/关闭减少动态效果；后台结束动画，恢复前台不重播旧变化。
