# 桌面 0.68 与安卓本分支的区别

桌面依据：Javis603/token-monitor `v0.68.0`，提交 `5d2db368d8313415763860d594de00e46a663418`。
安卓基础：The-Minion-oOo/token-monitor-android 0.67.0 r1。

## 本轮已对齐

统计、费用、工具、模型、设备、项目、会话、额度、趋势入口继续使用现有实现。补充未定价 Token、Codex observed-only 来源、规范化模型别名及自动分组、缓存未命中包含写入、费用符号与精度、独立字体角色、工具／模型／账户置顶排序、额度窗口选择、上下文方向、热力图指标与活跃天数范围、计时计数增量速率、只读订阅详情及提供方价值比较、隐私裁剪导出。

安卓设备名直接采用 Hub 的 deviceId，其次 hostname，不再应用旧安卓别名；旧偏好保留供回退。

## 保留的手机差异

| 能力 | 桌面 | 安卓 |
|---|---|---|
| 数据采集 | 本地工具扫描和采集控制 | 不采集，只读取 Hub |
| 账号登录与切换 | 访问电脑上的供应商凭据 | 不登录供应商，不控制电脑账号 |
| 共享数据编辑 | 部分桌面／Hub 设置可写 | 只读，不修改订阅、设备或服务端 |
| 窗口与托盘 | 托盘、多窗口、全局快捷键、Edge Dock | 手机页面、点击和系统返回 |
| 逐条会话内容 | 本地数据支持的详细对话 | 只显示 Hub 提供的统计，不虚构内容 |
| 图表交互 | 鼠标悬停、桌面大视口 | 点击提示、滚动，适应手机 |
| 主页趋势 | 桌面可显示 | 按用户要求不在主页显示，保留趋势页 |
| 二级 Token | 各视图可按桌面格式 | 按用户要求完整整数、不缩写 |
| 汇率 | 自动和手动，可带服务缓存 | 手动、每币种保存，不额外访问汇率服务 |
| 背景 | 电脑窗口透明、系统玻璃和背景图能力 | 现有主题与透明层次；未新增自定义背景图导入 |
| 字体导入 | 电脑系统字体及可配置字体 | Android 系统／等宽角色，未新增任意字体文件导入 |
| 实时速率 | 可按设备、模型细分 | 汇总计数增量；保留会话计时指标，未新增模型速率弹层 |
| 导出 JSON | 原始使用字段与历史，裁剪会话正文 | 支持字段的显式白名单；未来未知字段不会自动导出，不称为无损导出 |
| 后台／自动导出 | 电脑常驻条件下可自动执行 | 用户主动导出，退出前台停止常规同步；主动开启小组件 Live 时临时每60秒读取、最长一小时 |
| 小组件 | 电脑桌面集成 | Android 启动器组件，网格和尺寸由启动器决定 |

## 字体与文字细节

| 部分 | 桌面 0.68 | 安卓实现与区别 |
|---|---|---|
| 界面字体默认角色 | 系统等宽栈，随操作系统匹配 SFMono／Menlo／Consolas 等 | Android `FontFamily.Monospace`；可独立切换 SansSerif |
| 顶部大数字 | 系统无衬线显示角色 | `FontFamily.SansSerif`；可选择等宽或跟随界面 |
| 中文 | 桌面平台字体回退 | Android 中文字体回退，字形和宽度不会与 macOS 完全相同 |
| 大数字特性 | 等宽数字与显示层级 | `tnum`；字号随现有文字大小档位调整 |
| 当前大数字字号 | 桌面根据窗口与设置缩放 | 42＋2×step sp，行高 46＋2×step sp；step 为0／1／2 |
| 标题 | 桌面 CSS 与窗口密度 | titleLarge 20＋step sp；titleMedium 16＋step；titleSmall 13＋step |
| 正文与辅助文字 | 桌面常见10～12px并按字体比例缩放 | body 11～12＋step sp；labelSmall 9＋step sp；还受 Android 系统字体比例影响 |
| 字重 | 系统字体对应字重 | Compose 字重，标题和重要数据按现有组件设置；平台字体文件不同 |
| 热力图月份 | Canvas／桌面字体 | 与界面字体角色一致，9sp，包含系统字体缩放 |
| 小组件 | 电脑端原生组件字体 | 默认 JetBrains Mono＋系统 Sans；选系统或跟随时同步角色。Canvas 固定布局不能与 Compose 文本布局完全相同 |
| 专有字体文件 | 来自电脑系统安装 | 不打包 Apple／Windows 专有字体；保留既有 JetBrains Mono 许可 |

本轮保持已有字号尺度，字体角色与字号分别设置。完全相同的截图像素不是跨平台字体的验收标准；重点是角色、层级、数字可读性与触摸操作。

## 验证状态

已运行桌面0.68确切源码的隔离认证读取和SSE合约；使用合成数据，不访问真实NAS。Android12和16检查覆盖中文字体选项、设置迁移、设备列表、小屏、大字体及图标档位。每次最终构建的测试数及签名验证写入发布记录。

真实手机／启动器、已认证NAS联调和Android17仍未验证。自动汇率、自定义背景图、字体文件导入、模型实时速率弹层为明确未实现项，不把本版称为桌面功能百分之百复刻。
