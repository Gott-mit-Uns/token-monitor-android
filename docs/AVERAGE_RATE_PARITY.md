# 标题平均速率与直连验证

原始桌面v0.68.0固定提交`5d2db368d8313415763860d594de00e46a663418`的`currentTokenRateValue`、`tokenRatePerSecond`、`tokenBurnPerMinute`和`tokenRateText`定义标题处的平均读数：当前周期计时输出Token/计时时长，或全部计时Token/计时时长。它与底部最近生成记录的增量速率分别计算，不使用SSE间隔估算。

安卓将悬浮查看适配为长按Σ/标题打开紧凑只读提示；普通点击继续返回首页。提示显示当前周期，单位切换沿用已有`rateMode`与本机设置，不增加偏好版本。西文/本地单位、四舍五入后为0时隐藏读数、1e12上限及独立缺少分子等规则直接对照原始函数。原始计数、缓存和费用保持不变。

平均读数从周期自身计算，未沿用实时采样必须同时具备三项计数的门槛；输出与总计时Token可以独立缺失。原始平均函数不检查实时采样能力标记，安卓保留这一作用范围。派生历史周期没有计时字段则显示不可用。新快照即时更新当前提示，后台关闭提示，来源变化关闭旧提示。不加入原始标题按压时的装饰性虚构加速。

`tools/capture-average-rate.cjs`直接调用固定桌面函数与格式器，生成180组原始结果，覆盖英/简中/繁中、西文/本地单位、两种速率、缺值、负值、零时长、仅一个分子、超大值/溢出、数字字符串、不可用能力及0.49/0.5边界。安卓实际页面检查覆盖长按、单位、语言、周期、缺值、缓存更新、后台关闭和普通标题点击，确认不新增读取。

为验证正式客户端直接访问NAS，增加独立可选`LiveDirectLanTest`与`tools/check-direct-lan.py`。本机已有安全配置只在内存中读取，临时回环服务单次交接连接信息；正式MainActivity/client/default网络随后直接访问NAS GET/SSE，不经过数据桥接或ADB反向映射。测试不归档真实值、响应、画面、界面树或凭据，结束清除所拥有模拟器上的加密测试资料。该项只有实际通过才作为证据，不能代表Lucky HTTPS或实体手机。

整体目标继续进行；Lucky根地址仍等待答复，实体手机仍需实际证据。主页Token数字动效及上一版状态动效继续保留。
