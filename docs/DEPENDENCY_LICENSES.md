# 随包运行依赖许可

由精确解析的 debug/release 运行依赖生成，不包括 Gradle 构建工具、测试库或 Android 系统本身。各依赖的许可来自对应 Maven POM（含父 POM 继承）；发布者名称来自 POM。二进制中提供的 LICENSE/NOTICE/COPYRIGHT 原文按内容去重后保留，未改写。

完整文字随 APK 保存在 `assets/open-source-notices.txt`，设置页可离线阅读；上游 MIT 原文另存于 `assets/token-monitor-upstream-MIT.txt`。本表不为本项目原创代码指定许可证。

```
python3 tools/update-third-party.py --check
```
