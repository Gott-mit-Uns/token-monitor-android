# 主题、操作与历史恢复的桌面参照

固定参考桌面 v0.68.0，提交 `5d2db368d8313415763860d594de00e46a663418`。本轮为 0.2.43-dev / code52；最终通过范围与包哈希以 `evidence/theme-history-actions/final` 的封存报告为准。本文不会把单项测试或模拟器画面当作整体体验验收。

## 主题覆盖的存在性

原始 `styles.css:38` 给数字独立的 `--number: #f3fbf7`。`themePresets.js:148–177` 仅在合法的显式 text 覆盖存在时镜像 number；强调色、图表色和背景色不会改变这一用途。`app.js:7341–7350` 选择预设时只保存不同于默认值的键。

因此，“选择默认预设”和“导入包含默认正文色的主题码”具有不同语义：前者没有 text 覆盖，数字使用 `#f3fbf7`；后者明确包含 `text=#eef5fb`，数字使用 `#eef5fb`。不能因颜色刚好等于默认值而删除主题码中的显式键。

Android 的预设现在保存稀疏覆盖，Theme Code 仍保留显式键。旧偏好不迁移或清除，因为已经保存的 text 是用户可能有意选择的覆盖。总量和活动日期详情的数量使用独立数字色，单位和日期仍使用次要文字色；普通列表数字继续使用正文色。现有 LIGHT/SYSTEM 浅色基底无覆盖时采用浅色正文色，以维持平台可读性，属于明确的适配。

实际页面检查包括预设、默认主题码、强调色/图表色独立性、颜色弹窗预览与取消/应用、重置、私有偏好字节、Activity 重建和模式恢复。总量字形与弹窗颜色预览检查实际像素，活动提示检查真实 TextLayoutResult 的数字与单位跨度。首轮测试的捕获和重新进入折叠区错误保留在 `targeted-first-run.txt`，不改写成首次成功。

## 操作控件的完整状态

原始 settings-actions 最终视觉为 30px 高、8px 圆角、横向 10px 内距、11px 文字；禁用 opacity 为 0.38，作用于文字、背景和边框整体。背景图片操作为 26px 高、6px 圆角、4/7px 内距，禁用整体 opacity 为 0.5。连接编辑为 24px 高、4px 圆角、3/6px 内距和次要文字色，没有普通设置按钮的边框和背景。

Android 使用这些用途分别绘制视觉部分，操作范围保留至少 48dp。订阅和定价读取、连接操作及背景图片操作采用对应形态。连接没有实际改动时 Save 禁用；更换凭据的明确意图也算修改。Cancel 保留透明背景。连接编辑在忙碌时禁用是 Android 的串行事务适配，不把源中的鼠标悬停行为当成手机交互。

真实控件检查可用、忙碌禁用、错误后恢复、连接草稿修改/取消及图片选择/移除。禁用像素分别检查文字、边框和背景的合成透明度，不能只检查 Text 的颜色。原生颜色弹窗的 Apply/Cancel 继续使用平台操作形态，保留其 0.5 内容透明度。

## 全时费用与自动完整历史

原始 `src/shared/history.js:519–535` 的全时 summary 保留未定价数量；`dashboard.js:524–535` 根据该字段展示未知费用及排除数量。Android 过去解析 summary 时漏掉这一字段，导致完全未定价的用量显示为零费用。

现在 summary 保留精确的非负 Long 未定价数量。完全未定价且已知费用为零时显示 `—`；部分定价时保留已知金额，同时说明未定价数量；明确零费用仍显示零。币种转换只影响已知金额，不重算日历史或改变排除数量。旧 Hub 缺少字段时维持原始兼容语义，不从有限日窗口推断全时缺价。

原始 Home 完整历史读取在有日预览时采用首次读取加三次额外重试，每次等待 4 秒。Android 自动读取现在遵循这一预算，空的完整响应不会替换有效预览，成功的非空结果停止重试。同一版本的更新时间不重置等待或预算；换连接/历史版本才开始新预算。退出相关视图、后台或连接失效会取消资格和等待，回来后重新等待，后台经过的时间不会触发立即补读。所有请求仍经过原有串行只读队列；401/403 撤销 live，自动重试随之停止。

历史失效与在途响应检查优先使用非空版本号；旧 Hub 缺少版本号时使用 daily/monthly/summary 明确业务字段的规范 SHA-256。早期日回填、费用和汇总变化会失效旧历史；freshness、外部更新时间和未知字段不参与。实际 ViewModel、内存 HTTP/SSE 和加密缓存检查旧响应拒绝、新历史保存、新鲜度独立、认证失败及后台禁止读取，没有访问真实 Hub。

## 当前边界

自动恢复不代表手动刷新已经完全一致。当前显示的 loadedDays 无法区分旧非空历史与手动新请求的结果，直接手动读取也不会恢复已耗尽的同版本自动预算。原始 `app.js:5150–5184` 独立检查本次 fetchedHistory/resolved，`app.js:6867–6877` 的 forceHistory 重置预算。后续需要明确请求结果身份和手动重试边界，同时在失败时保留旧显示。公开原始函数证据已复现这一差异。

另有数据容量边界：合法 Hub 可生成超过 Android 当前响应和缓存上限的数据。下一阶段需要有界投影与兼容缓存，不直接取消上限；不能据当前公开小样例宣称任意规模都能读取。

本轮保留普通数字行为回归，不固定导出 33 帧，也没有测量本包 FPS。0.2.42 的 Window 指标仍归属于该版本。实体 Xiaomi、实际 NAS 局域网直连与 Lucky HTTPS 未验证；用户已说明手机暂不能连接，不重复索取。项目目标继续进行。
