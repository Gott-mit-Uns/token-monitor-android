# 0.2.6工具分类与模型明细

状态：0.2.6-dev（versionCode15）完成本轮工具明细范围。整体桌面体验与用户验收继续进行，测试计数不能替代用户认可。

## 来源与实现

固定基线v0.68.0/5d2db368d8313415763860d594de00e46a663418，renderer/toolDetails.js、app.js的工具展开和底部切换、styles.css的紧凑提示。Android独立实现，不引入旧Android fork业务代码。

工具只展开一项，底部在Token和模型之间切换，切换选择在当前页面交互期间保持。输入缓存命中/未命中比例以二者合计为分母，不把输出混入；已知正数小于1%显示“<1%”，其他按桌面取整。输出没有伪造比例，已知零未分类不多占一行，未知保持未知。工具下模型按数量、费用、名称排序，并标明其占工具总量的比例；数量未知保持未知，只有费用或未定价的条目仍可查看。

缺模型来源与来源明确提供空模型表不同：前者没有模型切换和编造的未分配行；后者按已知工具总量显示未分配余量。别名只作用于实际模型，不改名合成未分配行。工具只有模型数据时直接显示模型；分类不足时总Token详情提示不可用，不能补出零。正数量模型行可打开紧凑费用/未定价详情，实时更新、币种更新及明细撤回都跟随当前来源；撤回会关闭旧详情，恢复后不自动重开。

底部位置沿用桌面视图选择旁的切换；窄屏或大字将切换放在操作栏上方，以保留48dp触摸和完整数字。超长数字使用分行而非缩短。Token总量与模型费用使用8dp圆角、细边框的紧凑详情，与日期详情一致。原始统计/美元/加密历史不改，切换不发起额外GET，也不向Hub写入。
