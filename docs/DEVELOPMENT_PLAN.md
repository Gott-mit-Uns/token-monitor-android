## 协议与安全规则

| 接口 | 用途 | 调度 |
|---|---|---|
| GET /api/health | Hub 类型与 build 信息 | 连接验证；health 成功不能代替鉴权读取成功 |
| GET /api/stats | 主要快照 | 打开应用与手动刷新，读取一次 |
| GET /api/stats/stream | snapshot/stats/freshness 推送 | 仅前台连接；后台取消，回前台重建 |
| stats中的devices与periods | 设备详情 | 主快照用于 TODAY/MONTH/TOTAL；WEEK/7D/30D 另读 `/api/devices` 取逐设备历史（与桌面 historySource 一致） |
| GET /api/history | 完整历史 | 按需；history/deviceHistoryRevision 变化时失效 |
| GET /api/subscriptions | 实际支出信息 | 按需；subscriptionsUpdatedAt 变化时失效 |
| GET /api/sync/content | 可选能力 | 鉴权能力发现，旧 Hub 404 可降级 |
| GET /api/sync/settings/modelAliases | 共享模型展示语义 | 能力允许时按 syncSettingsRevisions 获取 |
| GET /api/sync/settings/customPricing | 查看自定义价格 | 已实现按需只读及共享版本失效 |

只允许上述读取路径；不实现 POST/PUT/DELETE。共享凭据可能仍具服务端写权限，应用只读并不代表凭据权限只读。

网络采用鉴权 header，不把凭据放 URL。系统证书校验，不绕过 HTTPS 校验，不自动将鉴权转发到重定向目标。明确识别 HTML/挑战页、401/403、429、5xx、超时与格式错误；401/403停止自动重试，429遵循可用 Retry-After。SSE仅前台开启，网络失败退避重连，鉴权失败停止自动重试；后台取消网络。请求失败保留已读取快照。

freshness 事件仅更新新鲜度字段，不能覆盖完整 usage 快照。history/订阅/设置缓存分别失效，设备随完整快照替换。总量来自 Hub；未分类 Token 独立展示，缺失数值不补零。unpricedTokens 存在时标注成本仅为已知价格部分；零成本本身不代表缺价格。期限按 Hub 日期窗口/来源时区，避免手机本地午夜重算出不同结果。0.2.0可显示鉴权stats中Hub已允许共享的会话标题，手机不决定同步策略、不上传标题或读取正文。收到撤销后的完整快照会替换旧加密缓存，已打开的详情按当前快照解析，避免继续保留旧标题；模拟器验证隐藏列表/搜索/详情、撤回时已打开的详情与新实例缓存恢复。真实NAS撤销链尚未联调。小组件不显示私有名称；本机隐藏标签只改变展示，原始快照继续加密保存。

Hub 连接信息由 Keystore 保护，排除备份；日志不记录鉴权、响应私密正文或完整连接配置。缓存放应用私有存储，有10MiB加密文件上限、来源更新时间和清除入口；没有定时到期删除，离线可持续查看最后快照。切换 Hub 时不串用缓存。普通后台不发起网络请求，不常驻服务或持有唤醒锁。小组件只读缓存，没有后台实时模式。

## 实现策略

候选栈：Kotlin、Jetpack Compose、Material 3、Coroutines/Flow、ViewModel、OkHttp、kotlinx.serialization、DataStore，缓存按快照和历史规模选择文件或 Room。正式创建工程前核对官方版本与本机 JDK/SDK；本规划不把未经验证的版本号当作已选依赖。Android 8/API26 为候选最低版本，target/compile SDK 以实现时官方要求与设备环境决定。

先采用单 app module，内部按 connection/network/protocol/repository/domain/ui/storage 划分，避免首版过度模块化。DTO 与显示模型分离，保留未知状态和可选字段。金额使用精确十进制展示，Token 使用64位整数并测试超大值。新增独立包名和独立签名，不自动继承旧 fork 的更新通道。依赖、图标和上游代码若有直接复用，逐项记录来源与许可证；独立实现不删除依法需要保留的归属说明。
