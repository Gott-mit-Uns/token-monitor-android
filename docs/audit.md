# Cloudflare 兼容性及代码审核

## 结论

适配可行。上游客户端与官方 Worker 的健康检查、Bearer 鉴权、统计／设备／历史／订阅读取和 SSE v2 协议基本一致。主要阻碍是客户端主动拒绝公网域名、所有地址默认使用桌面 Hub 的 17321 端口。无需迁移采集端或修改 Worker。

## 本版修复

| 问题 | 修复及保留行为 |
|---|---|
| 公网域名被拒绝，HTTPS 默认端口错误 | 允许有效公网 HTTPS 根地址，默认 443；保留 Tailscale 与显式启用的私网 HTTP |
| 地址含混、可能误带凭据 | 拒绝 URL 用户信息、查询、片段及非根路径；Secret 放在鉴权头中 |
| fallback 可能降级到任意公网地址 | fallback 限定私网，并提醒必须访问同一个 Hub |
| SSE 失败可能持续高频访问 | 前台单条 SSE，轮询后备至少 60 秒，重连退避最大 60 秒；401/403 暂停自动重试 |
| Live 小组件增加 Worker 请求量 | 可选实时模式改为每 60 秒、最多一小时；普通后台不新增定时请求 |
| 大型多设备历史可能超过上游读取限制 | HTTP 32 MiB、SSE 8 Mi 字符；仍保留明确容量边界 |
| 历史重复下载、错误统计与新鲜度事件处理 | 根据版本字段复用历史与订阅；拒绝缺少统计结构的错误 JSON；新鲜度事件只允许更新时间字段 |
| 大尺寸小组件图表被缩放 | 按实际布局测量图表空间生成位图，避免固定 dp 估算误差 |
| 缓存容量估计及读取分配边界 | 缓存按 UTF-8 字节计量，总计 96 MiB、单部分 32 MiB，避免字节与字符混淆 |
| Keystore 记录提交失败被忽略 | 检查同步提交结果；成功保存后才接受新连接 |
| 不同 store 实例并发密钥创建与配对读取 | 共享进程锁串行化整个读／写／清除操作 |
| 独立包名／签名无法安装上游更新 | 禁用上游更新网络检查和安装入口，移除 APK 安装权限，显示独立版本更新说明 |

## 原有优点保留

- 已有 Keystore AES-256-GCM，无需重新引入另一套加密实现。
- 已禁用备份，云备份与设备迁移规则排除全部应用数据。
- 原有完整统计界面、主题、小组件和私网连接继续保留。
- 健康检查要求真实 Hub 身份，鉴权请求不跟随重定向，系统 HTTPS 证书校验未关闭。

## 验证与限制

新增测试覆盖公网 HTTPS／默认端口、非法地址、私网 fallback、同步策略、缓存边界、更新禁用守卫，以及 Keystore 随机加密、篡改拒绝和多实例并发。测试存在不代表已经执行通过；本轮实际测试结果由交付报告单独记录。

没有访问用户真实凭据或修改其 Cloudflare Hub。共享 Secret 的服务端权限由现有 Worker 决定；客户端只读不会降低该 Secret 的服务端授权。缓存受 Android 应用沙箱和备份排除保护，并非逐文件加密。Keystore 失效需要重新连接。
