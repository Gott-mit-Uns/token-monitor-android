## 主窗口

Trends 默认显示共用 `DesktopTotal`，总量、费用、可选紧凑计数与 Token 组成按主窗口顶部周期选择。内容使用 snapshot.historyPreview；已读取的完整历史不会把这个概览换成另一个窗口。

DAY 先取源 daily 尾七条，再按本地今天构造连续七个日历日，今天柱使用当前 snapshot today total。跨日离线缓存不会把旧日的 today total 搬到新日。MONTH 的图取 preview 最后一日所属月份，统计的时间与峰值取本地当前月；这两种取法是原源码的分别定义。TOTAL 与 ready WEEK/7D/30D 使用全部 retained monthly，不额外截取十二条。四项按行排列：活跃天数 / 连续天数，活跃时间 / 峰值单日。前两项始终取 preview lifetime summary，后两项按 source 当前周期规则取值，固定周期只用 fixed.activity 的时间和峰值。

原 `usageCharts.js` 与 `homeOverview.js` 直接运行后的公开输入和输出保存在 `evidence/trends-main/reference-trends.txt`。规范日期排序抵消 Android parser 降序保存，Long 柱值不改成 Double；统计加法与时长格式使用 BigInteger，避免整数溢出。普通时长遵循原半分钟四舍五入；超过 JavaScript 安全整数的精确结果作为明确扩展，未声称与 Number 误差同值。

单色柱形使用独立共享 chart-bar 角色，普通柱透明度 .5，最后柱 1；DAY 零标记 .24 / .32。原样式的默认 bar 是 #6ab4f0，通用 chart-color 是 #73bdf5；原主题函数仅在自定义图色时同时覆盖两者，恢复默认后清除覆盖。公开原函数结果另存 reference-bar-colour.txt；实际像素检查包含自定义及恢复默认两个场景。300×120 是原 SVG 坐标系，最终高度随可用空间伸展。范围说明、首尾日期轴、2×2 四卡的字形、颜色用途、透明度、圆角与间距参照 source CSS。卡片数值在标题上方，使用正文色、16sp/600 与等宽数字；四卡准确文案使用 trends 专属中英文资源。触控入口保留 48dp，短屏与大字以自然内容高度滚动，不压缩或裁掉统计。

## 独立历史

点击柱图或 ↗ 打开详细历史，底部视图仍是 Trends，不新增并列主视图或更改用户顺序。详情隐藏主窗口 headline 和顶部周期，使用自身 7/30/90/365/全部范围。已有工具/模型、柱图/K线/折线、日期命中、八项摘要、Token/费用活动、日历展开、日/月列表和分页保留。它们的完整视觉仍按独立 Dashboard 继续核对，本轮首先修正入口层级。

返回按钮固定在顶部；系统返回先退出详情，再按原主视图规则返回。详情独立保留滚动、范围、图表模式、归因选择及活动选项；概览和详情不互写周期。设置往返保留详情状态，换 connectionRevision 清除详情路线及其旧状态。没有主预览或固定周期未就绪时，不伪造图与四卡；安卓保留独立“打开仪表板”动作，适配桌面托盘中的独立入口。

主概览刷新调用 refreshSaved，详情刷新调用 loadHistory。主概览不自动请求完整历史；详情沿用原有串行只读队列及自动读取策略，已有有效完整历史不因导航反复请求。原 43 的手动请求结果身份和预算重置缺口仍待后续修复，不将改变刷新入口说成解决了该问题。
