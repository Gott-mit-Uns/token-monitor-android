# 共享价格、订阅和模型规则对齐

2026-10-10，开发版0.2.8-dev（code17）。固定参考桌面v0.68.0提交5d2db368d8313415763860d594de00e46a663418。整体桌面体验和用户验收仍在进行。

## 本次行为

价格和订阅成功读取后，显示紧凑标题、记录数、摘要与列表；原先的读取按钮和整段来源说明收进“详情”。价格、订阅和设置页不显示无效的DAY/MONTH/TOTAL按钮，不因记住了WEEK/7D/30D而读取无关设备历史；回到用量页仍保留原周期。页尾刷新价格或订阅时只重读当前共享资料，模型页仍刷新用量统计，规则详情有独立刷新入口。

价格行遵循桌面customPricingMeta的缓存命中、输入未命中、输出、缓存写入、1小时缓存写入顺序。摘要只列已设置单价，使用USD/百万Token；点开查看全部五项，明确零价与未设置分别显示。普通、小数、极小数、科学记数和Double最短往返字符串直接对照桌面JavaScript，不使用用量费用的2/4位金额格式或人民币换算。源Hub成本没有用共享价格重新计算。

订阅行保留提供商、账户或方案、原币种金额、周期及续费/覆盖截止；充值显示本月记录合计与最近日期。点开查看按记录推算累计、起止、已订阅时长、完整充值和备注。月末续费一直以原始日期为锚点，取消续费有覆盖截止；未来开始和未知金额/周期/续费不补造有效数字。顶部每月等值按桌面规则汇总，使用所有已配置币种比率，转换为当前用量显示币种；原记录币种和金额仍保持原样。不支持或缺失的比率/金额使汇总保持未知，不将部分合计当作完整合计。本月充值合计包括该月的未来登记日期，累计已付则截至当前日，分别保留来源语义。

模型页成功读取后用紧凑规则入口替代反复出现的读取按钮。详情保留手动源名称到目标名称及off/duplicates/prefix模式，支持两端搜索、100条分页与独立刷新；全部规则都可翻页访问。未初始化和已明确写入空规则分别显示。原始模型用量不改写，不提供修改Hub规则的操作。

价格或订阅数据在打开详情时更新，详情跟随当前记录；来源撤回后关闭旧详情，恢复数据不自动重新打开。订阅优先使用来源唯一ID；缺失或重复ID使用稳定摘要和序号区分。模型规则撤回同样关闭旧弹窗并清除搜索。原始共享响应继续由既有Keystore缓存保存，没有增加偏好版本、运行依赖或后台轮询。

## 来源与实现边界

直接参考src/electron/renderer/app.js的customPricingMeta、订阅行/合计，以及src/shared/subscriptionDisplay.js、subscriptionText.js、currency.js和i18n.js。tools/capture-shared-display.cjs只加载这些固定纯模块，并从renderer提取不访问DOM的价格摘要函数；公开数据生成app/src/test/resources/shared-display-parity.json，不读取用户配置或真实Hub。

主要原生实现为SharedDisplay.kt、SharedDataUi.kt、PricingRow.kt及DesktopHubScreen.kt；HubSubscriptions保留来源ID/备注和覆盖边界，HubModelNames区分未初始化，UsageCurrency支持所有已配置币种的读取比率。未复制订阅编辑/删除、价格或名称规则写入、桌面提供商登录及本机采集。
