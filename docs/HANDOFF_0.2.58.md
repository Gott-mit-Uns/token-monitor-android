# 0.2.58 — 手机布局密度与字号反馈

2026-10-13，Asia/Shanghai。起点正式0.2.57/main 4aa4f1a，分支fix/mobile-density-058。仅完成用户指定的8项反馈，不处理其他待办或生产服务。

## 完成范围

- 导航菜单：普通字号最小行高48→36dp，上下文字内边距4dp；自然文本高度更大时增高。自然高度估算同步，保留全部八入口、滚动、选择、键盘和退出逻辑。
- 右下角：刷新/设置组成零额外间距的组，两键维持48×48dp独立点击区域及34×30dp原视觉尺寸。
- 常规区：正文和按钮统一11sp基础字号，小标题11sp/字重区分，说明9sp；由原有主题统一缩放。小组件/关于标题填满可用宽度，修正中文粗体自然宽度取整可能导致的边缘溢出。
- 设置展开区：局部密度上下文44dp控件最小高度，正文行间距8→4dp，区块垂直内边距10→6dp，顶部留白12→8dp。覆盖主界面、外观、工具、额度、共享入口和嵌套列表；大字号可以自然增高。共享控件在设置之外仍用原48dp默认值。
- 工具设置：显隐、置顶、排序、搜索及模型规则/价格入口保留，新增中英说明和README用途解释。显隐/排序控制手机工具页，不配置或启动工具，不改Hub总量；主页排行榜保持来源排名。
- Token缩写：13→15sp，同排空白8→4dp，按实际字形先给缩写预留空间，再适度缩小完整数字，最小24sp并保留系统缩放；确实放不下才换行。不省略数值，完整数字与缩写按基线对齐。
- 首页图标：工具、模型、设备列表及所有栏目图标使用实际sp→dp转换，立即响应应用字号和系统字号，遵循Android非线性缩放。
- README：浅色主页原图1000182520.jpg、深色主页原图1000182519.jpg逐字节复制；设置展示也改用用户的1000182516.jpg。删除旧演示PNG，明确照片为截图当时0.2.56界面。没有改写照片或数值。
