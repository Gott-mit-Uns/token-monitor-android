# 会话别名、无明细回退与一次变化提示

桌面基线为v0.68.0固定提交`5d2db368d8313415763860d594de00e46a663418`。直接核对`modelAliasPresentation.js`、`sessionRows.js`、`app.js`及原始`row-live-pulse`样式。独立Kotlin/Compose实现，不引入旧Android fork代码或本机采集。

桌面先在统计输入层应用模型别名，再生成会话标签。安卓在显示层应用同一规则：首页会话、完整会话和无明细时的模型汇总共用Hub只读别名，保存的统计、会话模型和加密原文保持不变。自动分组观察统计、设备、原生会话/项目以及历史预览中已知模型字段的标识，不遍历消息或任意未知字段；有界到原始16,384标识/256字符范围。合并计数用BigInteger，避免多个大Long值相加溢出。模型变成单一项后关闭旧多模型提示，避免失效弹窗重新出现。

无可用会话行且总用量非零时，按原始模型/工具汇总规则回退。模型别名、未归类余量、金额/Token排序和对应进度条保持一致；已有Hub聚合明细可以展开。派生周期不提供会话明细，仍遵循原始fixedPeriodRanges限制，不伪造会话记录。

完整会话页的5dp绿色点与1.5dp分离环沿用原始语义色；浅色成功状态为原始深绿，与自定义强调色独立。只有运行中会话的正时间戳超过前一次记录时触发一次1200ms提示。首次显示、相同时间戳的心跳、结束状态不触发；新提示按原始规则重新开始。两段CSS ease-out分别对应0/35%/100%关键帧。Android用固定Canvas径向晕光承载变化，不改变布局尺寸，归档的曲线数据来自真实桌面CSS计算样式。

减少动态效果、系统动态效果比例、后台停止和返回不重播均接入；只在有提示时请求显示帧。系统比例使用整套主题共享的观察器，避免每行注册一个。连接或周期变化的会话行使用独立显示作用域。没有为了动效增加Hub读取、定时轮询或后台任务。

## 动效检查

| Before | After | Why |
|---|---|---|
| `SessionListUi.kt`静态、受强调色影响的运行点 | 原始语义绿、时间戳推进才触发一次提示 | 区分正在生成和普通心跳 |
| 每行可能独立读取系统动态效果 | `TokenTheme.kt`共享系统比例 | 避免重复观察器和额外帧循环 |
| 周期/来源变化可复用旧行显示状态 | 行作用域包含连接与周期；STOP收束 | 防止旧变化在新来源或后台返回时重播 |
| 空会话只列出原始模型且不能展开 | 共用别名、排序、聚合明细投影 | 让回退与桌面及模型页一致 |

`tools/capture-session-parity.cjs`执行原始统计别名投影、会话回退和运行点更新函数，生成36组回退、18组全局别名上下文、3组时间戳序列及9帧真实浏览器CSS计算值。单元检查同时覆盖账号无关的超Long合并、原始数据保留及未归类份额。公开安卓界面检查覆盖排序/展开、首页与会话别名、多模型提示失效、首次/心跳/结束/后台/减少动态效果。

主页Token数字动效保持原始1000ms更新/800ms周期、连续中断、准确大整数与减少动态效果规则。Lucky公网、实体手机、其余整体桌面对齐及用户体验验收继续进行。
