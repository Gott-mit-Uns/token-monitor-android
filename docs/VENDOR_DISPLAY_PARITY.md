# 厂商颜色与列表、连接标记

2026-10-10，开发版0.2.9-dev（code18）。固定参考桌面v0.68.0提交5d2db368d8313415763860d594de00e46a663418，包含0.2.8共享价格/订阅/模型规则与此前对齐行为。整体体验仍在继续验收。

## 已接入行为

本机外观设置可选择全部59项厂商/默认颜色，按桌面vendorPresentation与themePresets顺序和名称排列。手机用选择列表与单项RGB输入保留完整目录，避免把59个编辑器同时铺满窄屏。支持单项或全部恢复品牌色，非法输入不提交。厂商色独立于五项界面主题色、字体与TM1/TM2；切换主题不清除厂商覆盖，主题代码不夹带厂商选项。

工具与模型用量条、额度条和历史堆叠图/图例使用同一份有效厂商色。修正旧实现自动提亮深色品牌色的行为，保留桌面与填写的RGB值；Factory额度按桌面借用Droid颜色。未知工具使用可设置的默认色，未知模型继续使用独立稳定颜色，不伪装成某个已知厂商。总Token、原始美元、费用换算与Hub数据不因颜色更改而重算。

显示列表图标开关按桌面适用范围处理：工具/模型/会话和设备标记可改为色点，订阅关闭品牌图形，额度提供商与工具管理入口仍保留原标记；视图导航和操作按钮保留。标题中的静态“Σ.”改为Σ与真实连接状态点，已连接使用主题强调色，离线使用桌面灰色。状态点可隐藏，来源详情/页尾仍报告连接状态；隐藏不停止SSE。没有复制桌面实时Token速率或托盘能力。

厂商颜色的应用和恢复会清除输入焦点、收起键盘，Activity显式采用adjustResize，保留已有设置表单imePadding，避免编辑器把标题与页面顶移。六配置交互会核对应用后键盘关闭且Σ仍可见；相关边距规则参考[Android窗口边距说明](https://developer.android.com/develop/ui/compose/system/insets-ui)。

## 兼容与来源

本机显示偏好V9在既有V8外观后追加厂商RGB和两项布尔值。V1–V8仍可读取，读取不重写旧文件；旧背景/图表色、独立字体与文字、工具、CNY/手动汇率、活动和周期选项保留，新增选项默认显示。非法键/颜色/布尔或尾部数据被拒绝，失败保存不改写原记录；全部厂商、工具与最长合法字体的设置仍在4096字节边界内。加密Hub连接、原始快照与明细格式未变，没有运行依赖或后台网络增加。

直接依据src/shared/vendorPresentation.js、src/electron/renderer/themePresets.js、usageCharts.js、breakdownRenderPolicy.js、app.js的limitProviderColor/showLiveDot与对应CSS。tools/capture-vendor-display.cjs只运行固定纯模块和独立提取的提供商颜色函数，生成公开参考与名称表；不读取真实配置或网络。原生实现为DesktopVendorPalette、DesktopVendorDisplay、VendorColorSettings及既有主题/列表/图表组件，使用HubScreen提供的同一份本机颜色。
