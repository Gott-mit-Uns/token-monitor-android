# 提供商额度页面与实际桌面渲染对照

2026-10-10，开发版0.2.11-dev（code20）。基线为桌面v0.68.0提交5d2db368d8313415763860d594de00e46a663418，参考目录没有本地修改。整体桌面一致性和用户体验验收仍在进行。

## 实际来源

工具capture-limit-layout.cjs在独立临时Edge配置中加载桌面原始windowsView、共用显示模块、styles.css与rowIconMasks。临时回环服务只提供已列明的静态源文件和公开演示记录；浏览器拒绝外部请求，结束关闭进程和监听。不读取桌面配置或真实Hub。164组提供商/显示方向/语言案例来自实际DOM行，比较标签、数值、顺序、模型分组、跨列、进度比例和色阶、边界、副行、稳定项目标识和明细，以及账户套餐和新鲜度。

额度数字按用户要求不缩写。正常窗口的固定英文数据标签、剩余/已用后缀、更新时间与边界遵守原页面；设置和明细仍支持中文与English。缺失/非法百分比或无法识别币种从严保留未知，不伪造0或USD。

## 已接入

按提供商排列窗口：Factory分Standard/Core池，Antigravity保留模型分组及原组内顺序，GLM按日/周/计划桶配对，账单/余额/消费行遵守各分支。OpenCode Zen余额、Cline余额合并消费说明、OpenRouter固定余额与附加额度、DeepSeek推算余额、MiMo Token Plan/赠送与现金拆分、Typesafe到期赠款与Tokens摘要均来自已命名字段。额度金额保留原币种与两位小数；部分透明进度条按原页面叠加在16%提供商色轨道上。

标题、账户、额度和重置文字分别采用原页面12/11/10/9字号层级及12dp标记、6dp进度条；窗口标签/数值尽量同行，长数字/名称换行，大字或窄屏改为单列。界面字体与本机/系统文字比例继续生效，账户可操作区域保留48dp。账户新鲜度和来源移到额度上方，不再加每账户箭头。套餐遵守分组/恢复状态策略，第三方适配器使用对应标记和固定颜色；查询失败显示原恢复标签，过期来源继续显示已有数据。

点击账户可展开只读消费/配额/请求/Token/响应时间明细及原窗口状态。明细邮箱继续遮罩。展示投影只接收明确的提供商、窗口、余额、用量字段，丢弃未知嵌套配置；同一账户窗口共享一个不可变展示记录，原始Hub缓存不重写。首页紧凑窗口保留Zed不限量窗口的显示副本。

显示偏好仍为V10，无新依赖；既有三个额度开关、59厂商色与显隐、外观、币种、周期、工具和首页选项继续保留。
