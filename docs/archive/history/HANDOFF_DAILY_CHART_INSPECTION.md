# 日粒度图表查看交接

本轮功能 4 接入独立 Dashboard 的 Trends 柱状图（工具/模型维度）和 Records 历史图的柱状/折线模式。继续使用现有日数据、坐标比例、Token 与费用格式、未知数据标记及工具/模型归因；不调用 Repository、HTTP、SSE 或逐点读取。

- 手指静止达到系统长按阈值并命中日期后才锁定；达到触摸滑动阈值、父滚动消费或离开命中区域的普通动作不抢占。锁定后横向移动连续选择，超出左右边界停在第一/最后日期。
- 指示线与受限高度的可滚动详情 Surface 随选点更新，松手保留。点击同一日期、图表外、关闭按钮或离开图表关闭。外部观察器不消费事件，外部操作继续执行。
- 以日期作为选点身份而非下标，正常快照更新不取消拖动，选日消失则关闭。模式/范围切换清除选点。单点允许选中、空图不制造选点；未知日期显示破折号，真实零值显示 0。详情显示当前维度和已知费用/未定价 Token。
- Dashboard 保留原有无障碍点击和前后记录详情操作；Records 加入前后日期无障碍操作并保留点击详情。无需仅靠长按手势。
- 没有新增动画，减少动态效果策略照旧；没有改原有图表动画。

接入范围和排除理由：Dashboard 和 Records 的 K 线沿用多日 bucket（开/高/低/收及覆盖率），不是一个明确的日数据点，保留既有单击 bucket 明细。首页趋势/主 Trends 是进入独立 Dashboard 的导航预览，原始点击导航保留。日历/热图是二维周/星期布局，左右相邻格并不对应相邻日期，继续使用现有单日按钮与前后日明细。月记录并非日粒度，不改。

定向测试源码：`DailyChartInspectionTest` 覆盖坐标、空图、单点、边界和反向；`DailyChartInspectionScreenTest` 覆盖长按拖动、零/未知、松手持留、外部/再次点击关闭、正常点击/滑动、快照更新和无障碍前后日期，并保存合成数据截图 `daily-inspection-missing.png`、`daily-inspection-history.png`。测试结果由主发布任务执行后补入；此文不宣称尚未执行的测试通过。真机拖动手感、长图滚动边缘及大字体实机未执行。
