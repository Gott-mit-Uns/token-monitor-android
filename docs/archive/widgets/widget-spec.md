# Hub 用量桌面小组件

沿用原生系统字体和现有薄荷绿强调色；平台 RemoteViews，不引入另一套 UI 依赖。四列四行起步（具体网格由启动器决定），最小280×360dp，可调整大小，正文可换行；完整 Token 数字，不缩写成 K/M。不放设备名、账户名、项目、会话标题、入口或凭据。

内容：Token Monitor → Hub 的今日 Token 范围 / 已保存 → 完整 Token 总数 → USD 已知估算成本 → Hub 数据时间与本机读取时间（均注明 UTC） → 48dp「打开并更新」区域。整张卡片也可打开应用。成本缺失显示未知；0 明确显示 0；有未定价 Token 提示成本仅含已知价格。

状态：无缓存提示先连接；缓存读取失败提示打开应用处理；快照没有今日字段不改用累计值；已有缓存始终标明已保存，跨日也不假装是手机当日最新数据。读取现有加密缓存，不建立 HTTP/SSE，不启用周期任务。应用成功保存快照、清除连接或改变语言/主题后更新组件。组件语言和主题跟随应用选择。

验收：通过真实系统 AppWidgetHost 添加、调整尺寸和更新；缺失/零/超大整数/未定价/缓存清除正确；提供者不可被其他普通应用调用、仅主屏幕、周期为 0；主屏幕更新没有网络连接；48dp 操作且放大字体不裁掉数据。物理启动器验收另行记录。

API36及以上通过not_keyguard类别声明不用于锁屏；不把第三方启动器执行情况当作已验收。千位分组后提供软换行点，TalkBack说明为未插入换行符的完整数字。
