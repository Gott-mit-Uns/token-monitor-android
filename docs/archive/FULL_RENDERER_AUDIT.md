# 桌面完整渲染页面对照

0.2.33-dev/code42 继续以桌面 v0.68.0 的固定提交 `5d2db368d8313415763860d594de00e46a663418` 为基线。此前部分工具仅运行单个原始组件；本轮增加完整页面运行方式，用整页核对信息顺序、默认状态和组件比例。整体目标及用户验收仍未完成。

`tools/capture-full-renderer.cjs` 直接加载未修改的原始 index.html、app.js、样式及全部页面依赖，并运行原始 preload.js。替代 Electron IPC 的内存桥只提供公开合成数据，原始主进程、系统配置、采集、账号操作和 Hub 网络均不运行。本地文件服务器只允许参考源码路径下的 GET，浏览器拒绝外部和写入请求。固定源码的提交及工作区差异检查通过；报告包含实际使用的 167 个原始文件 SHA256。

两种语言共 26 张完整原始页面截图：八个主页面、工具展开、带共享别名的模型/项目/会话，以及设置。第一组统计和历史沿用现有安卓公开样例，第二组模型/项目/会话沿用另一组公开样例。桌面主进程会先投影模型别名，因此桥接前调用其实际纯函数 projectModelAliasStats；未手写合并后的显示结果。完整渲染无浏览器错误、失败请求或外部请求。固定时间同时覆盖 Date.now 与无参数 Date，避免日历读取电脑当天时间。

窗口为 400×780 CSS px，原始玻璃窗口通过公开外观设置改为不透明，减少动态效果开启。此运行方式不证明已安装桌面端的系统玻璃效果，也不等于真实 Hub 或实体手机测试。并排预览部分页面的日期、滚动和展开状态不同，尚未作像素等价验收。

## 本轮修正

完整页面暴露了工具和模型主列表仍使用通用 Material 标题字体及 18dp 图标的问题，虽然数据和展开检查通过，视觉比例仍偏大。本轮按原始实际计算样式恢复：

| 部位 | 原始参考 | 安卓调整 |
|---|---|---|
| 名称与完整数量 | 12px，400 字重 | 12sp，正常字重，沿用共享字体与文字缩放 |
| 费用 | 10px，400 字重 | 10sp，沿用原始币种和精度 |
| 品牌图形 | 10×10px | 10×10dp |
| 费用与数量间距 | 2px | 2dp |
| 行内标题与条间距 | 6px | 6dp |
| 用量条 | 高 6px，深色底层透明度 0.46 | 高 6dp，共享主题深色底层透明度 0.46 |
| 行末间距 | 10px | 10dp |

标题和用量条组成同一个最小 48dp 触控区域，不再给紧凑标题单独添加 48dp 高度。展开明细仍是独立区域，明细内部操作不收起外层。大字、窄屏或长数字时保留完整数量的下行布局。工具/模型数据、排序、展开能力、读数和费用计算没有改变。

原始总量标签在中英文均直接写为 TOTAL TOKENS，中文资源据此恢复同样文本。主页 Token 更新动画实现没有修改，并从本包重新录制实际 33 帧；首次、减少动态效果及后台返回行为继续验证。
