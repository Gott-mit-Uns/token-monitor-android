# v0.66.0-hub.1

本分支以 Android 上游 v0.66.0 r2 的兼容性和可靠性改动为基础，桌面基线为 Javis603/token-monitor v0.66.0（e7bac3aff6a1bc7cf74fd149a26d2730cfe32de8）。不是桌面功能的完整移植，手机继续作为只读 Hub 客户端。

## 更新

- MiniMax Code 的名称、厂商图标与协议样例。
- NAS／电脑 Hub、HTTPS 域名、Tailscale 与局域网说明，移除 APK 内 Cloudflare 版本文案。
- 家庭地址可复用已保存密钥验证；认证失败保留原连接。Android 17 局域网权限处理。
- 额度提示按紧迫度排序；趋势保留缺失日期空缺、显示未分类统计；搜索支持清空。
- 小组件增加紧凑、横向、竖向、总览、详细五个具名入口，保留自动适配与四页切换，共七个入口。Pages 四个页面不是四个独立尺寸。
- 小组件按启动器给出的实际 dp 尺寸生成 RemoteViews；旧启动器按横竖屏尺寸回退，避免强制放大尺寸。网格行列因启动器而异。
- 小组件 Live 最多一小时，使用单调时钟处理到期、息屏与恢复；手动刷新有超时。常规前台 SSE 与 60 秒后备轮询保持。
- 保留中文、设备别名、黑白品牌及 NAS 图标、图标与文字独立档位、主页万／亿、二级完整数字、Keystore 和排除备份。
- 保留活动标题翻译与主页趋势图移除，趋势详情继续保留。
- 修复中文本地化 Context 与新增权限 launcher 的 ActivityResultRegistryOwner 冲突；增加真实 MainActivity 冷启动回归测试。

## 安装

应用 ID 与原固定签名保持不变；versionCode 660101。直接覆盖旧 cf 版本，无需卸载。已放置小组件仍保留原 Provider 名称；新增样式在启动器添加菜单中选择。

## 验证范围

176 项单元测试通过（包含官方 0.66.0 独立 Hub 合成接口与 SSE 契约测试，无跳过）；Android 16 完整设备测试 85 项、Android 12 针对性测试 26 项通过；追加实际 MainActivity 中文冷启动回归测试在两种系统均通过。原签名 release APK 在 Android 16 模拟器覆盖安装并启动成功，已有语言偏好保留。升级检查的原 App 无已保存 Hub 凭据，不宣称已验证真实凭据的跨版本迁移。合成数据测试不代表真实手机启动器、已认证 NAS Hub、Android 17 或长时间电量验收。
