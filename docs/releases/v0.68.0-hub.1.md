# v0.68.0-hub.1

直接跟进桌面 Token Monitor 0.68，继续保留安卓上游基础与本分支设置。应用 ID 和固定签名保持不变，versionCode 为 680101。

设备名称跟随 Hub，安卓改名入口停用；旧别名偏好保留但不再覆盖显示。新增未定价 Token 和 Codex observed-only 提示，校准缓存分类、费用精度与符号。新增独立字体角色、规范化模型分组、工具／模型／账户置顶和拖动排序、额度窗口选择、活动指标与上下文方向、计数增量速率、只读订阅详情及提供方价值倍数。

导出支持 JSON、CSV 和四文件 ZIP，CSV 使用 UTF-8 BOM；费用保持原始 USD，保留 Hub 原始分类并裁剪正文与凭据。未知未来字段不会自动导出，未宣称无损导出。

[功能和字体差异](../reviews/desktop-068-current.md) · [代码来源核对](../reviews/upstream-code-retention.md)。自动汇率、自定义背景图、字体文件导入和模型速率弹层未实现，继续明确保留手机平台差异。

验证：204 项单元／协议测试通过；Android 12 通过 55 项设备测试，Android 16 通过 59 项设备测试及 2 项横屏测试。使用官方桌面 0.68 固定提交的隔离 Hub 核对认证、读取接口及 SSE 事件。原签名比对、从 v0.67.0-hub.3 覆盖安装及冷启动通过；合成数据覆盖字体、图标、布局、缓存与安全存储。发布附件提供 validation.json 与 SHA256SUMS。真实手机／启动器、已认证 NAS 联调和 Android17 尚未验证。此版本不修改 Hub、不增加后台刷新，也不自动升级桌面或 NAS 容器。
