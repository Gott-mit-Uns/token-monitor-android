# Token Monitor Android v0.65.0-cf.2

本次加入简体中文和安卓本地设备改名，继续使用现有 Cloudflare Hub 协议、包名和固定签名。直接安装 APK 可覆盖 cf.1，不需要卸载；卸载会清除应用数据。

## 中文

- 默认跟随系统，提供简体中文／English 手动选择，首次连接页也可切换。
- 主页、导航、设置、连接提示、统计明细、日期倒计时、小组件与实时更新通知同步中文化。
- 术语参考桌面端 Javis603/token-monitor v0.65.0：主页、工具、设备、模型、项目、会话、额度、趋势、总 Token、剩余等。
- 品牌、工具／模型名称和用户项目／会话名称不翻译。

## 设备改名

进入“设备”点击“设备改名”，设置“安卓本地名称”或恢复原名。名称最多 32 个 Unicode 字符，去除首尾空白，不接受换行或控制字符。主页设备摘要与设备列表统一显示别名，设备列表保留 Hub 原名。

别名只保存在手机，按 Hub 地址摘要和设备 ID 隔离，不更改 Hub、电脑或 NAS 的名字；同一设备离线后继续保留，相同 ID 再出现时恢复显示。
