# Token Monitor Android v0.65.0-cf.1

基于 The-Minion-oOo/token-monitor-android 的独立 Cloudflare 兼容版，保留原界面、主题与桌面小组件。无需修改现有 Cloudflare Worker 或采集设备。

## 配置

安装 APK 后在 Hub address 输入现有 Hub 的 HTTPS 根地址（不追加 /api/stats）；Secret 使用 Token Monitor Hub 共享凭据。Home Wi-Fi fallback 通常留空，仅支持同一个 Hub 的私网入口。不要在 issue 或截图公开真实凭据。

## 修改

- 支持公网 HTTPS，默认 443；保留私网与 Tailscale 连接。
- 前台单条 SSE，失败后以至少 60 秒间隔读取统计，重连退避最大 60 秒；401/403 暂停重试。
- 小组件 Live 模式每 60 秒刷新，最多一小时；普通后台不新增定时刷新。
- 版本字段复用历史与订阅缓存；严格校验响应，扩大并限制数据容量。
- Keystore 加密保存补强提交检查与并发保护，保留备份排除。
- 修复大尺寸小组件图表尺寸误差。
- 独立包名与固定签名，关闭原版自动 APK 更新，可与原版并存。

## 验证

121 项单元测试通过；Android 12 与 Android 16 各 42 项设备测试通过，另 8 项合成截图测试通过。APK 已完成 v2/v3 签名校验与两个模拟器安装。真实手机、用户 Cloudflare Hub 及所有启动器尚未联调，不宣称已完成日常使用验收。

APK、源码 ZIP、SHA256SUMS 与合成截图随 Release 提供；签名私钥及凭据不在仓库或附件中。遵循上游 MIT 许可。
