# v0.68.0-hub.6

按反馈恢复手机桌面启动图标的原有视觉比例：中央Σ从hub.5的48×54dp缩回约33×38dp。通过原位图与10dp内缩计算，改版前白色标识约32.6×38.0dp；现在的矢量为33.6×37.8dp并保持居中。蓝色背景继续铺满系统遮罩，不恢复原位图产生的深色外圈。

本次只改启动图标前景尺寸与版本信息。应用内16／20／24dp的内容图标设置、文字大小、主页设备用量排序与零用量过滤、两行设备二级列表均保持hub.5的实现。Hub协议、同步频率、凭据、缓存和统计代码不变。

版本为v0.68.0-hub.6，versionCode为680106，沿用应用ID与固定签名，可直接覆盖hub.5，无需卸载。

Android12已验证先安装hub.5，再覆盖安装hub.6并冷启动成功；APK签名证书与hub.5一致。此检查使用独立模拟器，未接触真实手机或其连接配置。

Android12（API31）及Android16（API36）的原生图标测试各1项通过，核对居中、恢复后的尺寸、铺满的蓝色背景与无深色外圈。预览APK及设备测试APK构建、Lint和固定签名release构建通过；Lint为0错误、120警告、2提示。维护检查确认共享核心、存储、Hub地址处理与既定基础保持一致。此图标尺寸修正未重复运行整个统计测试集。
