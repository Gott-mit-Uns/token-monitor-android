# v0.68.0-hub.5

本版只优化启动图标及设备显示，继续使用0.67 hub.2加安卓上游0.68的功能基础。versionCode提高到680105，沿用应用ID和固定签名，可覆盖hub.4。

启动图标原来把自带圆角和透明留白的PNG缩在深灰背景内，形成深色外圈。现在采用铺满的蓝色背景和独立Σ矢量前景，复用现有通知图标的Σ形状；108dp图层、48×54dp前景位于中央66dp安全区域，圆角由启动器决定。提供monochrome图层支持系统主题图标，运行时不下载素材。[Android自适应图标规范](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。未取得HyperOS3真机验证，不宣称已通过其启动器验收。

主页设备按当前周期Token用量降序排列，只显示大于零的设备；相同用量保留Hub顺序。有正数缓存用量的过期设备仍显示用量和过期提示。切换周期重新排序和过滤，不把聚合总量填入缺失的单设备统计。设备二级页保留完整列表，包括零用量设备。

设备二级页在常规字体下改为两行三列：名称／系统、同步状态／更新时间、Token／费用。图标垂直居中，各列边界统一；完整Token和金额保持单行，保留用量条与点击展开。展开查看完整名称和系统信息。窄屏、大字体允许文字自然增高；完整数字不改为缩写。设备名仍跟随Hub，不恢复安卓改名。

192项单元测试通过，无失败或跳过，包含新增的周期排序、零用量过滤、过期缓存与稳定顺序测试。Android12和Android16各35项相关设备测试通过，随后各15项最终布局／图标／偏好检查通过；包括360dp、字体1.0／1.5／2.0和16／20／24dp的实际图标宽度核对。Lint、文档与维护边界检查通过。签名与hub.4一致，Android12验证直接覆盖安装并冷启动。最终截图记录见Release附带validation.json。

APK SHA-256：`1a5fbf4feed8f129467dfe836ed6cd22a7fb69476ec3432dc4d164084a2e6411`。Release附带APK、源码、截图、验证记录和SHA256SUMS。

加上各4项最终主页／设置截图检查，两个系统各40项相关设备测试最终通过。截图排序断言首次比较了可点击模块合并后的同一无障碍区域，已改为比较实际文字节点并复测通过；App排序实现无需修改。改版前后设备图采用同一份合成数据。

发布后的CI小屏检查发现两项截图断言读取了屏幕外设备的空位置。测试已改为先滚动到设备区域再比较，截图前返回顶部；额外360×640dp的4项截图检查通过。此补充只修改测试及说明，APK和应用生产代码不变，源码附件纳入该修正；原发布标签保留。
