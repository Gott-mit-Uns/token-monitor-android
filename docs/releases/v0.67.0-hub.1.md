# v0.67.0-hub.1

## 来源与新增能力

基于安卓上游 android-v0.67.0-r1，桌面协议基线为 Javis603/token-monitor v0.67.0，提交 338a965f6c9a5a06b017eba4ebd7d5997973519e。

- TM2 主题代码包含独立图表颜色，应用于热力图、趋势上涨蜡烛和小组件图表；原 TM1 和预设主题继续兼容。

- 新增文案继续提供简体中文。

## 与本分支功能的关系

没有发现需要替换的重复功能。桌面模型别名与安卓设备别名不同；桌面独立文字大小不改变安卓的文字／图标独立档位。保留原中文、设备别名、NAS 图标、品牌黑白图标、主页万／亿、二级完整数字、凭据加密、域名接入、七个小组件入口以及现有同步频率。

桌面新增的采集器、模型分组／定价写入、标题共享控制和主页可选额度进度条，不因安卓版本号同步而自动移植。安卓上游此次也未实现这些设置，仍由电脑端或 Hub 提供数据。
