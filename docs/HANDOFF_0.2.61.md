Release 单元 446 项通过。任务专用 API36 模拟器 emulator-5596，合成/公开 fixture；没有实体手机。最终候选的开关/额度 Widget/隐藏额度导航/紧凑菜单复测通过；320dp/系统字号2.0/深色下 15 项图表、更新页、紧凑菜单及字体选择通过。Widget 实际系统宿主 280×360、400×440、280×480 和最小 280×360/font2 的文字、双周期、48dp入口与边界检查通过，保留截图。

证据 evidence/four-features/ 保留全部首失败、每轮 APK 指纹和截图。首次冻结包26项定向回归通过；窗口矩阵320dp/字号1.0发现测试长文案自然高度仍可落在36dp最低值，测试却无条件要求更高。只将合成长文案改为明确多段换行，继续严格检查完整文字、自然增高、滚动与无障碍，产品布局未改。最终精确签名 APK、8组窗口矩阵、升级与发布回读须在新冻结提交构建后记录于 Release 四附件 VALIDATION.md、release-manifest.json 及发布回执。此源码交接不代表已经发布。
