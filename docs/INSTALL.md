## 连接

更改连接先验证新地址并原子保存，再一起替换来源。失败保留原连接和缓存，编辑草稿及原因保持；取消恢复原摘要。更换Hub或账户后重新读取对应明细。详见CONNECTION_TRANSACTION_PARITY.md。

1. 安装开发APK并打开应用。
2. 在设置页的连接区域填写Hub根地址，不包含/api路径、查询参数或登录信息。外网地址使用Lucky等反代提供的HTTPS，局域网HTTP当前支持RFC1918数字IPv4地址。
3. 可同时填写HTTPS和局域网HTTP两个入口，两者应属于同一个Hub并使用同一凭据。凭据只在应用内输入，不写入命令、截图、日志或文档。
4. 点击连接。验证health和鉴权stats成功后，连接与快照写入Keystore加密缓存。打开时默认选择HTTPS，前台接收SSE，后台关闭网络。

Android 17及以上连接局域网需要系统局域网权限，设置页提供“允许访问局域网 Hub”入口。授权窗口不再出现时，点击“打开系统应用设置”，进入权限并允许局域网访问；系统可能把它显示在“附近的设备”组。系统设置单独打开，点应用图标可返回Hub页面。授权后再次连接或切换。公网HTTPS通常不需要此权限；HTTPS域名若在家中解析为局域网地址，也需要授权。

未授权的私网HTTPS可能由系统表现为连接超时。应用保留网络、证书与地址排查提示，并补充局域网授权提示；这不是把每次超时都认定为权限问题。撤销系统权限后已加密保存的快照仍可查看，重新打开时停止HTTP；恢复授权后在前台重新读取。

同一Wi-Fi/有线IPv4网段允许手动切换HTTP；系统尚未确认网络、网络丢失或VPN成为默认网络时停止HTTP。HTTP连接固定到已确认的本地网络，不经过系统HTTP代理。双入口模式每次返回前台或默认网络变更后优先HTTPS，即使新网络使用同样的私网网段也会恢复HTTPS。已经使用HTTPS时，默认网络变更也会关闭旧连接并重新读取。没有HTTPS入口且网络不匹配时提示配置并停止HTTP。子网匹配不能证明服务身份，两个入口应由你确认指向同一Hub。

HTTPS失败不会自动试HTTP。鉴权被拒绝（401/403）后自动重连保持停止，切换网络和回到前台不会继续重复提交；修改连接或主动刷新后可以再次验证。断网保留此前快照，恢复联网时在前台更新。

主页显示额度、设备、年度活动与近期趋势。活动图和趋势使用当前今日总数/费用的展示副本，完整历史未加载时可用快照预览；不会改写原始历史。设置可选择费用或Token着色，以及全部/近一年活跃日，选择保存在手机。过日旧缓存不会把昨日today搬到新日。设置中可显示/隐藏模块并调整完整顺序，隐藏项也能移动；恢复显示保留位置。显示全部不重置顺序，重置顺序不改变显隐；最后一项被隐藏时按桌面规范恢复显示全部。活动图选项位于设置的主界面→主页→活动配置图标，采用原始胶囊选择。日历下方月份按每月1日所在列定位。点击日格查看当天详情，或用“查看当天详情”及上一天/下一天按钮；实时更新保留日期，未知记录不补零。点击总Token查看完整分类；缺字段保持未知。主页图表在前台自动读取，离开应用后不继续读取。

设置中的“工具列表”可展开，搜索工具，点单行眼睛或置顶按钮；点↕打开上移/下移菜单。输入框右侧可清除搜索。未手动排序时按用量显示，置顶优先；移动普通工具切换为手动顺序并清除置顶。工具视图与主页摘要共用设置，隐藏不减少总Token或总费用。可分别重置顺序/置顶或全部显示；搜索期间暂停移动，清空搜索后恢复。

工具和模型显示Token、费用与分布条；工具一次展开一项，底部切换Token／模型。Token明细显示输入缓存命中/未命中、输出和必要的未分类，并标明输入占比；模型明细按工具用量显示占比，可点开费用与未定价详情。缺模型来源不拼造未分配行，缺分类保持未知；缓存写入已包含在未命中输入内。工具下模型来自Hub，别名分组合并数量、费用、已知未定价和分类。只有费用或未定价的条目仍显示，缺数量/费用保持未知。

设置中的“显示币种”可选USD/TWD/HKD/CNY，非美元可选内置/手动比率；进入手动先填当前值，用键盘完成、失焦或确认保存，空或非法值恢复内置；内置比率来自桌面固定版本，不是市场即时汇率。主要用量页面与小组件共用格式，选项保存于手机。未定价数量明确保留，原始Hub美元不改。额度/订阅仍显示来源原币种，共享价格仍用USD/百万Token。

设置里的“外观”可选择默认、黑曜、瓷白，以及标准/较大/最大文字；总 Token 与图标不随应用文字选项放大，系统文字大小继续生效。界面字体和总量数字字体可分别选默认/系统/等宽/自定义，数字可跟随界面。自定义只使用手机已有字体，不下载；找不到时使用系统字体。主题代码在高级定制之外，当前代码可直接编辑、复制或粘贴并应用，支持桌面TM1/TM2，非法输入不覆盖已有值。展开“高级定制”可调整五种RGB颜色，独立图表色保留品牌堆叠和状态色；点色块打开十六进制/RGB弹窗，拖动或输入有效值立即预览整套界面配色，取消恢复原色，确认后保存；进入后台清除未确认预览。选项只存本机。

额度保留各个Hub账户记录，多个同套餐账户分别显示，账户身份与套餐分开。设置的“额度显示”可选剩余/已用、遮罩账户邮箱和显示来源；首页、额度与订阅共用遮罩，同名通过工作区和不透明后缀区分。金额按来源币种两位小数完整显示，余额/消费与已用百分比按各自规则呈现；无条或不限量不补进度。额度按提供商自己的窗口顺序与模型组显示，余额/消费/到期赠款使用各自明细；新鲜度和来源位于额度上方。点击账户展开只读明细及原窗口状态。设备显示当前周期用量与费用，点击查看来源窗口、时区、版本和采集诊断。设备改名只影响手机显示。

趋势支持7/30/90/365天和全部记录，按工具或模型堆叠的柱状图、K线和折线。图表可点击查看日用量或K线区间，保留日期缺口；K线首末日缺失时保持未知。年度活动可按Token或费用着色，并可展开适合触摸和辅助功能的逐日控件。Hub历史概要和月度记录独立保留。

项目/会话可搜索并打开用量摘要；设置可隐藏标签。Hub没有提供原始本地会话正文，因此手机不读取正文。订阅列表保留账户、原币种、续费/覆盖截止和每月等值；点开查看时长、累计、全部充值和备注。共享价格列表点开全部五类单价，区分未设置、明确零价与空配置。两页右下刷新只读当前资料；来源说明在“详情”。模型规则在模型页独立入口，可搜索源/目标名称并完整翻页，详情有独立刷新。

断网仍可查看缓存。页尾可打开来源时间详情；设置中可清除保存的连接和缓存。首次安装需要在应用内输入连接，不将凭据放入截图、命令或文档。
