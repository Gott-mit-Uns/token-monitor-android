## 当前实现

支持中文、English和跟随系统语言，并保存选择；界面与错误提示本地化，Hub原始名称保留。采用桌面端Σ标记、顶部周期选择、底部视图菜单和设置入口；宽屏内容保留阅读宽度；支持保存浅色、深色、跟随系统主题，以及本机隐藏项目与会话标题的显示选项；始终展示完整数字。

- 前台连接Hub SSE，接收完整快照与新鲜度事件；后台/退出取消连接及重连任务，返回前台重建连接。
- HTTPS反代和RFC1918局域网IPv4 HTTP双入口，共用Hub凭据，加密保存并可手动切换；每次回到前台或默认网络变更后优先HTTPS。局域网内手动选择HTTP，不因HTTPS失败自动降级。
- 局域网HTTP等待默认网络信息完整后才允许连接，连接固定到对应Wi-Fi/有线网络并绕过系统代理；网络更换或丢失立即关闭旧连接。HTTPS随默认网络变化重新验证，断网保留缓存，401/403保持停止状态。
- Android17局域网授权可从应用设置页请求；连续拒绝后可单独打开系统应用设置，重新点应用图标能回到Hub页面。未授权的HTTPS连接失败时提示核对局域网权限，同时保留网络、地址与证书排查提示。
- Keystore AES-GCM保存连接与最新快照，恢复快照后读取Hub；存储失败明确提示，提供清除入口。
- DAY、MONTH、TOTAL用量与已知估算成本；MONTH槽第二次点击展开MONTH/WEEK/7D/30D。快捷范围按每设备日历窗口、时区和完整历史推导，总量、费用、工具、模型与设备共用结果；缺设备历史保持不可用。主范围与菜单模式保存。原生周期提供项目/会话与工具下模型明细；快捷范围不提供的归属明确提示。
- 多账户额度窗口、余额、已用金额与可选支出上限、原币种、到期/重置类型、来源状态与更新时间；明确报告未定价用量时提示费用不完整。
- 用量费用统一按USD/TWD/HKD/CNY符号和桌面阈值显示2/4位小数；本机比率覆盖与内置来源提示，V7保存。未定价/仅费用条目、别名合并及未分配余量保留，原始Hub美元不改；额度/订阅原币种和价格单位独立。
- 设备详情保留来源窗口和时区、操作系统/版本、采集诊断观察时间；历史用量与当前扫描状态分别显示。

同一工具的`--case back`独立验证实际返回键、退出期间无读取与Activity重建后的加密恢复，适用于API31以上测试模拟器。运行需要明确的`--adb`、`--serial`、`--output`，会清理所选模拟器上本应用的测试资料；不用于实体手机。证据与边界见docs/VALIDATION.md。

`--case network`另验证实际模拟器Wi-Fi→蜂窝→Wi-Fi的默认网络变化，使用正式客户端及真实NAS只读桥接。旧SSE取消并退出安卓运行队列，蜂窝拒绝HTTP，回Wi-Fi不自动降级，手动切换可重连HTTP；Home/Launcher返回再次优先HTTPS。HTTPS使用`.invalid`失败样例，不代表Lucky公网成功。网络丢失时主机可能收不到关闭信号，工具会清理遗留桥接读取；结束恢复原Wi-Fi设置。该检查要求所选模拟器原本已启用Wi-Fi和移动数据。
